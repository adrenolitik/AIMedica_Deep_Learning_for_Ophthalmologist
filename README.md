# 👁️ Глубокое обучение для здоровья глаз (AIMedica)

Интерактивное приложение для офтальмологов: модель глубокого обучения анализирует снимок глазного дна и определяет признаки **диабетической ретинопатии (ДР)**, а тепловая карта **Grad-CAM** показывает, на какие участки сетчатки модель обратила внимание при принятии решения.

## Интерфейс

- Двухколоночная раскладка: слева — загрузка снимка, справа — результат анализа
- Тема оформления **Soft** (Gradio Themes) со скруглёнными элементами
- Кнопка **«Проанализировать»** с автоочисткой загруженного снимка
- Готовые примеры снимков (кнопка запускает анализ одним кликом)
- Вывод: тепловая карта Grad-CAM, вероятности по классам (gr.Label) и вердикт с уверенностью модели
- Загрузка изображений: файл, буфер обмена, веб-камера

## Технологии

- **Модель:** ResNet-50 (PyTorch), дообученная для бинарной классификации ДР
- **Объяснимость:** Grad-CAM (pytorch-grad-cam)
- **Интерфейс:** Gradio

## Запуск локально

```bash
pip install -r requirements.txt
python app.py
```

## Структура проекта

| Файл | Назначение |
|---|---|
| `app.py` | Приложение Gradio: предобработка, инференс, Grad-CAM |
| `resnet50_dr_classifier.pth` | Веса обученной модели ResNet-50 (~94 МБ, Git LFS) |
| `requirements.txt` | Зависимости Python |
| `examples/` | Демонстрационные снимки для быстрой проверки |

## Важно

⚠️ Приложение носит исследовательский и демонстрационный характер и **не является медицинским изделием**. Его результаты не заменяют консультацию врача-офтальмолога и постановку диагноза.
