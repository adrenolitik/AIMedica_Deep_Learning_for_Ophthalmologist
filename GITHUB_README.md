# 👁️ Глубокое обучение для здоровья глаз (AIMedica)

Интерактивное приложение для офтальмологов: модель глубокого обучения анализирует снимок глазного дна и определяет признаки **диабетической ретинопатии (ДР)**, а тепловая карта **Grad-CAM** показывает, на какие участки сетчатки модель обратила внимание при принятии решения.

Онлайн-демо (Hugging Face Space): [aimedica/AIMedica_Deep_Learning_for_Ophthalmologist](https://huggingface.co/spaces/aimedica/AIMedica_Deep_Learning_for_Ophthalmologist) — интерфейс и документация на русском языке.

## Как пользоваться

1. Загрузите изображение сетчатки (глазного дна) — файлом, из буфера обмена или с веб-камеры.
2. Модель (ResNet-50) отнесёт снимок к одному из классов: **ДР** (диабетическая ретинопатия) или **Норма**.
3. Результат: тепловая карта Grad-CAM с выделением значимых областей, вероятности по классам и вердикт с уровнем уверенности модели.

## Интерфейс

- Двухколоночная раскладка (Gradio Blocks): слева — вход, справа — результат
- Тема оформления **Soft** (Gradio Themes)
- Готовые примеры снимков — анализ одним кликом

## Технологии

- **Модель:** ResNet-50 (PyTorch), дообученная для бинарной классификации ДР
- **Объяснимость:** Grad-CAM (pytorch-grad-cam)
- **Интерфейс:** Gradio

## Метрики качества модели

Авторы исходного Space не публиковали точные метрики конкретной модели (`resnet50_dr_classifier.pth`). Ориентировочные значения для архитектуры ResNet-50 на датасете **APTOS 2019 Blindness Detection** (Kaggle, 3 662 снимка глазного дна с градацией ДР по шкале ICDR 0–4) при бинарной классификации:

| Метрика | Типичное значение ResNet-50 (бинарная классификация ДР) |
|---|---|
| Accuracy | 93–96 % |
| AUC-ROC | 0,94–0,97 |
| Sensitivity / Recall | 90–95 % |
| Specificity | 92–96 % |

Публикации с бенчмарками: [Lin et al., 2023 — revised ResNet-50 для DR (PMC)](https://pmc.ncbi.nlm.nih.gov/articles/PMC10114328/), [Robust binary & five-class DR classification на APTOS 2019 (arXiv, 2025)](https://arxiv.org/html/2507.17121v1).

> ⚠️ Указанные значения — ориентиры из открытых исследований на APTOS 2019, а не сертифицированные метрики этой модели. Не используйте их для клинических решений.

## Научные источники о диабетической ретинопатии

- **[APTOS 2019 Blindness Detection](https://www.kaggle.com/competitions/aptos2019-blindness-detection)** — датасет Kaggle: 3 662 снимка глазного дна, собранных в сельских районах Индии, с градацией тяжести ДР по международной шкале ICDR (0 — нет ДР … 4 — пролиферативная ДР).
- **[Gulshan et al., JAMA 2016](https://jamanetwork.com/journals/jama/fullarticle/2588763)** — классическая работа Google: глубокое обучение для детекции ДР по снимкам глазного дна (датасет EyePACS), AUC 0,97–0,99.
- **[Lin et al., 2023 (PMC10114328)](https://pmc.ncbi.nlm.nih.gov/articles/PMC10114328/)** — обзор методов на базе ResNet-50 для градации ДР по данным APTOS 2019.
- **[Robust binary & five-class DR classification (arXiv 2507.17121)](https://arxiv.org/html/2507.17121v1)** — современный SOTA на APTOS 2019: accuracy 98,9 %, AUC 0,994 для бинарной классификации.
- **[ICDR шкала тяжести ДР (AAO)](https://www.aao.org/eyenet/article/international-clinical-diabetic-retinopathy-severit)** — международная клиническая шкала тяжести диабетической ретинопатии, используемая для разметки APTOS.
- **[Grad-CAM: Selvaraju et al., ICCV 2017](https://arxiv.org/abs/1610.02391)** — метод визуализации внимания свёрточных сетей, используемый в приложении.
